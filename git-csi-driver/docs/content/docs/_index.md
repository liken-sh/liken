# The `git-csi-driver` manual

The [guides](/docs/guides/) show how to install the driver, mount a
repository read-only, give an application a writeable volume that the
driver commits and pushes, and share one repository between many
applications. The [reference](/docs/reference/) describes the volume
attributes and class parameters that the driver reads, and the
`Event`s and metrics that it reports.
