# Authoring this docs domain

@themes/brand/voice.md

This directory is the source of https://people.liken.sh/,
people-operator's manual. Hugo builds it with the shared brand theme,
taken as a git submodule at `themes/brand`.

Write all site prose in Simplified Technical English (ASD-STE100): short
sentences, active voice, one instruction per sentence. The voice rules in
that file add what the standard does not state. They govern every word
this site publishes, so scan a page against them before you commit it.
