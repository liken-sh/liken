# Reference

These pages cover the API resources, how a node makes its hardware
available to workloads, the kernel settings, resource limits, and disk
settings that the OS applies, the layout of the release channel, the `liken`
command, and the metrics that each operator serves.

The `Machine`, `Cluster`, `Disruption`, and `MachineDisruptionBudget`
pages are generated from the CRD schemas, so they match what the API
server validates.
