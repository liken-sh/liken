# Guides

Start with the [install](/docs/guides/install/), then
[declare a `Player`](/docs/guides/declare-a-player/) for each screen.
The other guides cover one task each:
[map a controller](/docs/guides/mapping-a-controller/) whose codes
nobody has written down,
[hand the idle screen to another program](/docs/guides/handing-the-idle-screen-to-another-controller/),
[record what a player is playing](/docs/guides/record/), and
[claim a GPU by what it decodes](/docs/guides/claim-a-gpu-by-capability/).
The [reference](/docs/reference/) describes each resource.

[Players, plays, and their pods](/docs/concepts/how-the-pieces-fit/) explains
the model behind these steps.
