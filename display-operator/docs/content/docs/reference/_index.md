# Reference

The reference describes each interface of `display-operator`: the
device classes, the devices and their attributes, what a prepared
claim gives a container, the `Display` that the operator creates for
each monitor, the `Layout` that a `Display` names, the Wayland
protocol that a claim's arranger uses to place the claim's windows
inside its region, the HTTP API that returns screenshots and video of
a screen, and the metrics.
