# Writing for this site

@themes/brand/voice.md

Every word this site publishes follows the voice rules above, and the
base under them is ASD-STE100: short sentences, active voice, plain
words, one instruction per sentence. The rules travel in the theme
submodule at `themes/brand`, so the pin that carries the site's shell
also carries its style.

Build the site with `go tool hugo` from this directory. The output
lands in `dist/site/`, which git ignores.
