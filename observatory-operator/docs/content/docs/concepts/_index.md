# Concepts

These pages explain how the operator works: how the resources relate
to each other, what a reservation does from start to end, how the
FITS keywords that you declare get into each frame, how procedures
and triggers run, how the dome and the mounts refuse to park or
unpark while the other one is in the way, and how the guider runs PHD2. The guides give the
steps for each task, and these pages give the reasons behind them.
