# Guides

Each guide is a task. For a first night, follow them in this order:
[Install the operator](install/),
[Describe your equipment](describe-your-equipment/),
[Connect USB equipment](connect-usb-equipment/), and
[Reserve a telescope](reserve-a-telescope/). Install runs a whole
observatory of simulators, so you can see every part work before you
connect any hardware. Then
[Automate the equipment](automate-the-equipment/),
[Set up a portable telescope](set-up-a-portable-telescope/), and
[Guide with PHD2](guide-with-phd2/) add what your site needs.
[Troubleshoot](troubleshoot/) starts from the step that failed or
waits.
