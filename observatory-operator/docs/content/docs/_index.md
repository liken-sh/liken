# Manual

The manual has three parts. The concepts explain how the operator
works: the resources, a reservation from start to end, procedures and
triggers, the dome and mount locks, and the guider. The guides take
you from an empty cluster to a reserved telescope that KStars drives:
install the operator, describe your equipment, give it the USB devices
it needs, reserve a telescope, automate the equipment, and guide with
PHD2. The reference lists the drivers and their images, what
each status field means, the objects the operator creates, and every
field of the 20 resources.
