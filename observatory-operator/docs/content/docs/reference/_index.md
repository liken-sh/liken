# Reference

The first pages list the drivers and the images that contain them, what
each status field means, the pods, `Service`s, and labels that the
operator creates, and the Prometheus metrics that it serves. The
resource pages list every field of each resource. They are generated
from the CRDs in the `deploy/` directory of the repository, so their
descriptions are the ones that `kubectl explain` shows.
