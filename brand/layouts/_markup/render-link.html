{{- /* Every manual writes its links to its own pages from the site's root, such as /docs/guides/install/, so the same Markdown reads the same in the repository and on the site. Each component's manual is served under its own path, such as liken.sh/media/, so this hook puts the site's base path in front of a root-relative link. Without it, /docs/guides/install/ on the media manual would open the OS manual's install guide. A link to another host, a protocol-relative link, a relative link, and a fragment pass through as written. The Markdown twin keeps the authored link, because it renders from RawContent. */ -}} {{- $dest := .Destination -}} {{- if and (hasPrefix $dest "/") (not (hasPrefix $dest "//")) -}} {{- $dest = relURL (strings.TrimPrefix "/" $dest) -}} {{- end -}} {{ .Text }}
