# Guides

The guides follow the order in which you set things up:

1. [Install the operator](/docs/guides/install/).
2. [Declare a library](/docs/guides/libraries/) for each directory
   of media on a volume.
3. Learn what a [scan](/docs/guides/scanning/) reads, and the
   [catalog](/docs/guides/catalog/) that it writes.
4. Put the [media browser](/docs/guides/browser/) on a screen.
5. Add titles, plots, and art from metadata providers with
   [enrichment](/docs/guides/enrichment/).
6. Connect Radarr, Sonarr, and Jellyfin
   [webhooks](/docs/guides/webhooks/), so an import rescans its
   folder at once.
7. Declare [franchises](/docs/guides/franchises/), a library of
   films and series in story order.
8. [Keep progress the same in Jellyfin](/docs/guides/jellyfin/).
9. Check what to expect on a
   [small machine](/docs/guides/small-machines/).

[Libraries, the catalog, and the screens](/docs/concepts/how-the-pieces-fit/) explains
the model behind these steps.
