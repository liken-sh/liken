# Flux

Kind knowledge for Flux's `Kustomization`, `HelmRelease`, `GitRepository`, `OCIRepository`, `HelmRepository`, and `Bucket`.
With it, `transect` reads which `Kustomization` or `HelmRelease` applied each object, the source and revision it applied, and the `ServiceAccount` a `Kustomization` applies as, and links its code on a known forge.
