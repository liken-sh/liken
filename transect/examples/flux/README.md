# Flux

`KindKnowledge` resources for Flux's `Kustomization`, `HelmRelease`, `GitRepository`, `OCIRepository`, `HelmRepository`, and `Bucket`.
With them, `transect` shows which `Kustomization` or `HelmRelease` applied each object, the source and revision it applied, and the `ServiceAccount` that a `Kustomization` applies as. When the source is on a known forge, `transect` links to the code.
