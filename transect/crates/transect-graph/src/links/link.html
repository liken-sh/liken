{#- An object's name wherever a page shows it: a link to its page when it has one, and plain text when it has none, so no name links to a page that does not exist. A click on the link replaces the page's body and pushes the link's URL onto the browser's history, so the link works the same inside the main column and in a card. `class` adds the caller's own classes to either. `shown` writes a name such as `Kind namespace/name` with its namespace and its name each in a `name-part` span, which wraps as a whole, so a narrow box breaks the name after its slash before it breaks at a hyphen inside it. Text with a space after its last slash is not a name, and `shown` writes it unchanged. -#} {%- macro shown(text) -%} {%- if let Some((head, tail)) = text.rsplit_once('/') -%} {%- if tail.contains(' ') -%}{{ text }} {%- else -%} {%- if let Some((words, namespace)) = head.rsplit_once(' ') -%}{{ words }} {{ namespace }}/ {%- else -%}{{ head }}/ {%- endif -%} {{ tail }} {%- endif -%} {%- else -%}{{ text }} {%- endif -%} {%- endmacro -%} {%- macro object_link(text, href, class) -%} {%- if let Some(href) = href -%} {% call shown(text) %}{% endcall %} {%- else -%} {% call shown(text) %}{% endcall %} {%- endif -%} {%- endmacro -%} {#- A value that is not an object's name, such as an address or a list of channels, with a `` after each `,`, `.`, `/`, `:`, and `-`, so a narrow box breaks it after a separator and not inside a word. `links::pieces` cuts the text, and each piece is escaped. -#} {%- macro spelled(text) -%} {%- for piece in transect_graph::links::pieces(text) -%} {%- if !loop.first %}{% endif -%}{{ piece }} {%- endfor -%} {%- endmacro -%} {#- The link of `object_link` for a value that is not an object's name, such as an address that leads to the page of what it reaches. It writes the value with `spelled`. -#} {%- macro value_link(text, href) -%} {%- if let Some(href) = href -%} {% call spelled(text) %}{% endcall %} {%- else -%} {% call spelled(text) %}{% endcall %} {%- endif -%} {%- endmacro -%} {#- A sentence with the objects it names linked, from `Linker::link`: each name with a page is a link, and the words between are text. -#} {%- macro sentence(parts) -%} {%- for part in parts -%} {%- if let Some(href) = part.href -%} {% call shown(part.text) %}{% endcall %} {%- else -%} {{ part.text }} {%- endif -%} {%- endfor -%} {%- endmacro -%}
