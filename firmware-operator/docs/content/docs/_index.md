# The `firmware-operator` manual

The guides show how to install the operator, write a `Firmware` for a
device, read the firmware updates that the operator found, approve one,
and find out why an upload, a scan, or an update failed. The concepts
explain when the operator starts an upload and how it decides the
result, and how it finds, rehearses, and applies updates. The reference
lists every field of a `Firmware` and a `FirmwareCatalog`, with the
description that the resource definitions give it.
