# The `firmware-operator` manual

The guides show how to install the operator, write a `Firmware` for a
device, read the firmware updates it found, approve one, and find out
why an upload or a scan failed. The concepts explain when the operator starts an
upload, how it decides the result, and how discovery works. The
reference lists every field of a `Firmware` and a `FirmwareCatalog`, with the
description that the resource definitions give them.
