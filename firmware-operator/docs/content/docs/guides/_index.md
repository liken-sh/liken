# Guides

The first guide installs the operator. The second writes a `Firmware`
for a device and reads its status. The third reads which firmware
updates the operator found for each machine, and the fourth approves
one of them. The fifth finds out why an upload failed, why a scan
failed, why a machine was never scanned, or why an approval is
`False`.
