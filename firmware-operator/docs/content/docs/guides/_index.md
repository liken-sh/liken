# Guides

[Install the operator](/docs/guides/install/) first. [Upload firmware
to a device](/docs/guides/upload-to-a-device/) writes a `Firmware` for
a device and reads its status. [Find firmware
updates](/docs/guides/find-updates/) reads which updates the operator
found for each machine, and [Approve a firmware
update](/docs/guides/approve-an-update/) installs one of them.
[Troubleshoot](/docs/guides/troubleshoot/) finds out why an upload, a
scan, an approval, a rehearsal, or an apply failed, or why a machine
was never scanned.
