# The `equipment-operator` manual

The guides show how to install the operator, declare a `Receiver`,
and [connect a USB-CEC adapter](/docs/guides/connect-a-cec-adapter/) so
that a `CECBus` and a `Television` wake the room's TV. The reference
lists every field of the `Receiver`, `CECBus`, and `Television`
resources, and the metrics that the operator serves.
