# Reference

These pages give the details that you look up: the two API resources,
how a node makes its hardware available to workloads, the kernel
settings and the resource limits that the OS applies, the layout of
the release channel, and the `liken` command.

The Machine and Cluster pages are generated from the CRD schemas in
the repository. They always agree with the rules that the API server
applies.
