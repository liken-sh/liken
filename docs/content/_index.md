# `liken`

![The liken mark: a patch of lichen drawn as hexagonal tiles](/brand/liken.svg "A patch of crustose lichen. Each tile is one areole.")

`liken` is a small operating system. It boots a machine directly into
Kubernetes.

The project is one repository. It contains a Go init written for this
project, the Linux kernel and k3s from their upstream releases, and the
build that assembles them into a bootable image. Read the repository to
see what your machine runs.

[The repository is on GitHub.](https://github.com/liken-sh/liken)
A `liken` cluster built from it serves this page.

Releases are at [releases.liken.sh](https://releases.liken.sh/).
[The manual](/docs/) gives the steps from a release to your own
running cluster.
